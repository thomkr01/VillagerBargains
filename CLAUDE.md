# Villager Bargains

Fabric mod for Minecraft. Run `./gradlew build` to compile, run the unit tests and the game tests (see `CONTRIBUTING.md`).

## Writing rules

Apply the `unslop` skill to all prose you write: code comments, Javadoc, commit messages, PR text, README and docs, and replies.

## Before opening a PR

Run `/simplify-pr`. It runs the ponytail, pstack and thermo-nuclear passes over the diff, applies the fixes that keep behavior identical, then runs the build and tests.
